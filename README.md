# Warranty Manager

Ứng dụng web quản lý bảo hành sản phẩm, theo dõi ngày mua, thời hạn, lưu trữ ảnh hóa đơn trên máy chủ và hiển thị cảnh báo khi sắp hết hạn.

## Tính năng
- Quản lý CRUD sản phẩm bảo hành.
- Tải lên ảnh hóa đơn / phiếu bảo hành.
- Tính toán tự động thời hạn và trạng thái (Còn hạn, Sắp hết hạn, Hết hạn).
- Tìm kiếm và lọc linh hoạt.
